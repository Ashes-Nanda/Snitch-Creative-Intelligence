# Proposals have no "Running" status

The PRD asked for "Mark as running", but this system has no connection to Meta or Google, so it cannot know whether a test is running. A Running status would just be a person's claim, presented as execution state. Proposals therefore go Draft → Needs review → Approved | Rejected, and an approved proposal ends as Completed (with a won, lost or inconclusive outcome) or Not run. Add Running back only together with a real execution feed.
